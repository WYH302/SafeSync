# 分层状态确认实验：读取新地区前冻结

日期：2026-10-29。本文件和各地区的 `run_spec.json` 在读取八个确认地区像素前写入。开发集为原四地区中的后两地区；这里不再选择阈值、摘要大小、JPEG质量、模型或方法权重。

## 问题与比较

检验一种可以在发送端本地维护的小型历史摘要，能否在严格更新预算下保留有用的新建筑细节。发送端不保存历史RGB，不逐次接收地面参考图；地面保存档案，另接收当前低频信息与绝对JPEG区域。本文不将未知类别评分作为主方法，也不将随机投影或历史复用本身称为首次提出。

输入为 `data/spacenet7_pilot/confirmation_manifest_v1.json` 的全部8个新AOI、186个月产品、178次更新。各AOI首月是共同PNG bootstrap。后续按真实月份顺序处理，缺月不补，原始大小/配准网格不缩放；64像素补边不进入离线有效区评价。发送端不读GT、有效区、建筑mask或模型预测。首月并非免费：记录完整bootstrap下行和ACK，给出摊销及不含bootstrap的更新成本。

更新下行上限为32,768、65,536、131,072 bytes；全部方法另计60 bytes ACK。横轴采用实际发生的字节数，不用名义cap冒充相同实现码率。没有发送预算填充。

## 冻结方法

- Gaussian摘要：side=4，24个联合RGB投影/64×64块，q16步长1/256，4×4均值格，risk horizon=32，区域风险0.05。独立预选seed为20261029、1729、2718；不按结果选seed。
- DCT+尾范数：同样side=4、同一状态/图像编码/质量门。
- Full-cache MSE：发送端保存并维护实际解码历史RGB，按精确复用误差路由；其额外历史内存计入。这是有更多历史信息的参考策略，不称为全部指标的全局上界。
- Random：相同Gaussian质量门和载荷，待更新块按固定随机序排序，seed为1729、2718、31415。它用于分开质量门与优先级排序的影响。
- 全图JPEG 4:2:0、JPEG2000、WebP：使用IF06真实容器，允许五个固定空间尺度；在各自严格字节cap内以发送端当前RGB MSE选择可行质量/尺度。输出只从实际码流解码，必要时在接收端固定bicubic还原尺寸。

分层方法固定JPEG 4:4:4 q60绝对区域、64×64块、16×16均值单元、25 dB复用门。接收端档案与当前均值分开保存，渲染不写回档案。摘要只从实际发出并ACK的解码区域替换。确认实验不改变这些选择。

## 固定评价与汇总

所有指标来自完整序列实际接收端。任务评价使用已固定公开SN7单模型，权重SHA256为 `8135967879f5e42635508251739e2e9e30e4a58e3abc5df9875340ebc0be7081`，静态阈值0.5、新ID事件差分阈值0.961。模型训练地区重叠情况单列；它是统一任务失真评价器，不用于宣称任务网络的地理泛化。

主要报告：(1)建筑分割F1；(2)新ID建筑事件F1；(3)新ID像素所在64×64单元的masked PSNR≥30 dB覆盖；(4)全有效区RGB PSNR；(5)实际上下行、初始化、发送端历史摘要、共享矩阵和完整链路耗时。25/35 dB是预定质量敏感性结果。新ID相对首月官方ID集合定义，不等同于准确施工时点、未知语义或任意未来任务；所有事件有效区同时满足首月和当前mask。

先在每AOI内累加计数计算任务F1/证据覆盖，再对8个AOI等权平均。月份与像素不是独立样本。无正例分母用null，明确报告有效AOI数。随机/测量seed先在AOI内平均，不将seed扩充为新的地理样本。

全部方法跑像素质量；为控制推理成本，固定任务模型首先评价Gaussian seed20261029、DCT、full-cache、random seed1729及三个全图codec的全部三预算。其他seed的像素质量用于测量/排序稳定性，不能据此宣称它们的任务F1已经评价。

主比较为预选Gaussian与WebP，完整列出另两个codec、DCT及full-cache，避免按每个AOI挑赢家。对AOI配对差值给出固定seed=20261029、10,000次AOI重采样的区间，同时保留8地区原始值。三预算差异同时展示；正式同时区间采用每比较98.333%区间控制三预算家族错误率。开发结果/确认结果分开。

若讨论“已知任务相当”，预先采用建筑F1差值−0.02作为研究内部容差，并报告区间是否支持；它不是期刊门槛。若代价或F1不相当，仅报告真实多目标取舍，不宣称同效用省流量。可用证据覆盖绝对变化与相对变化同时给出。统计、实际意义与投稿判断分开。

## 数学与实现边界

Gaussian界仅覆盖STABLE块的RGB复用误差，有限候选联合范围为单区域32次外生观测，整体物理序列独立于一次抽取的矩阵。固定JPEG解码块不能依赖atlas排列；本环境的4:4:4对齐检查已通过。概率相对于理想高斯抽样；float32/PRNG不是形式化机器算术证书。UPDATED/DEFERRED、任意语义与跨会话风险不自动受该界保证。DCT界的数学形式确定性，但同样未形式化浮点舍入。

每地区保存源文件快照、manifest/config/模型hash、逐包与ACK、实际长度、接收RGB hash和原始指标。源配置差异必须另建运行目录；确认结果不用于回调当前方法。当前实验无丢包；丢包/ACK损坏仅能由独立协议小序列说明，不能替代真实链路可靠性测试。
